# Протокол испытания документа

**Режим испытания:** Аналитическое испытание по модели интерфейса (на основе `operator_observations.md`). Реальный стенд не использовался. Поле «нажал» отражает логический переход по модели, а не факт физической работы.

| Шаг (Сценарий) | Ожидание (по руководству) | Наблюдение (по модели интерфейса) | Требуемое уточнение / Статус |
| :--- | :--- | :--- | :--- |
| **1.3** (Создание) | Нажать «Отправить», увидеть сообщение со ссылкой. | Подтверждено: «Заявка LAB-104 создана» со ссылкой «Открыть». | Уточнение не требуется. |
| **2.3** (4-й файл) | Увидеть ошибку, текст сохраняется. | Подтверждено: «Можно приложить не более 3 файлов», текст остается в форме. | Уточнение не требуется. |
| **3.2** (Тайм-аут) | Увидеть ошибку, перейти в список. | Подтверждено: «Не удалось получить ответ. Проверьте список заявок перед повтором». | Уточнение не требуется. |
| **3.4** (Исход А/Б) | Проверить список, найти или не найти. | Подтверждено (Сценарий O-03): `operator_a` после тайм-аута нашел LAB-105 в списке. | Добавлено явное разделение на Исход А и Исход Б в v1.1. |
| **4.4** (Техник) | Нажать «В работу», затем «Отметить выполненной» с комментарием. | Подтверждено (Сценарий O-02): `technician_a` перевел LAB-101 в `in_progress`, затем `resolved` с комментарием. Кнопки удаления нет. | Уточнение не требуется. |
| **5.2** (Доступ) | Увидеть отказ, вернуться к списку. | Подтверждено: «Нет доступа к этой заявке», ссылка «К списку». Закрытые сведения скрыты. | Уточнение не требуется. |
