# Матрица ролей и словарь терминов

## Матрица ролей
| Роль | Создание | Чтение | Редактирование | Смена статуса | Назначение |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **Оператор** | Свои заявки | Только свои | Только свои открытые | — | — |
| **Техник** | — | Только назначенные | — | `open` → `in_progress` → `resolved` | — |

*Примечание: Удаление заявок не разрешено ни для одной из ролей.*

## Словарь терминов
1. **Заявка** — запись о проблеме, которую необходимо решить.
2. **Номер** — уникальный идентификатор (например, LAB-101). Используется для точного поиска и открытия конкретной записи. Не заменяется номером кабинета или другими числами.
3. **Статус** — текущий этап выполнения (`open`, `in_progress`, `resolved`). Показывает, на чьей стороне находится заявка.
4. **Вложение** — файл формата PDF или PNG (до 5 МБ). Максимум 3 файла на заявку. Нужен для передачи скриншотов или документов.
5. **Исполнитель** — техник, которому менеджер назначил заявку для выполнения работ.
